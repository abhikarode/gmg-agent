# Need-based recommendations and Marathi

The member finder accepts a description in Marathi, English, or both, and an optional hard location filter. Nemotron expands the request into professional search concepts. Search retrieves candidates from the installed GMG directory, and Nemotron ranks that bounded set. Every result must identify a real member and show the recorded experience that informed the recommendation.

The app gives an exact search separately, reports no strong evidence or model failures honestly, and avoids sending contact details, names, or profile URLs to the ranking step. Both the Vercel session allowlist and Mac API credential apply.

Member cards show a short fact-based role and company summary from the original LinkedIn export when a reliable identity join exists, or a labeled directory summary. Use the existing profile URL when recorded. Preserve the AlmaShines member and job scope and never imply current LinkedIn verification or willingness to help.

Acceptance: real English and Marathi requests return plausible results with evidence. The location filter remains strict. Results show source labels and verified-format LinkedIn links when present. Forms and result labels include readable Marathi. Test model errors and privacy boundaries, run project checks, then verify the Mac and Vercel deployment against actual sources.
