# Isolated GMG Flex sign-in test

This temporary harness tests the real LinkedIn OpenID Connect round trip and GMG's existing keyed email matching on Functions Flex. Use the 512 MB on-demand configuration, zero always-ready instances, an expiry, a separate Standard LRS storage account, and a dedicated disposable resource group. The live Container App, production storage, and inference endpoints are outside the harness's runtime dependencies.

Stage `function_app.py`, `host.json`, `requirements.txt`, `templates/` and `static/` alongside the repository copies of `membership.py`, `directory_snapshot.py`, and `azure_storage.py`. Copy `public/garje-marathi-logo.png` into the staged `static/` directory. Package the staged files at the root of the ZIP and use the Flex remote build. Set `GMG_FLEX_ORIGIN` to the verified HTTPS Function App origin and `GMG_FLEX_EXPIRES` to the Unix timestamp for the end of the test window. Supply `LINKEDIN_CLIENT_ID`, `LINKEDIN_CLIENT_SECRET`, `GMG_FLEX_SESSION_SECRET`, `GMG_FLEX_ROSTER_SECRET`, `GMG_FLEX_ROSTER_MEMBER`, and `GMG_FLEX_ROSTER_UNMATCHED` via protected app settings. Use independent random secrets for the Flask session and the roster, and generate the two small rosters with `membership.build_roster`. Include only the approved, verified test member's match key and a separate synthetic control. Keep the raw email, credentials, and test keys out of the package and test evidence.

Publish a synthetic versioned directory with the existing snapshot format in the sandbox's private `gmg-directory` container. Set `GMG_BLOB_ACCOUNT_URL` to the sandbox's blob endpoint and give the Function App's managed identity Blob Data Reader on that container. Publish `landing.html` as `index.html` alongside `desk.css` and the logo in the isolated static website and set `GMG_FLEX_LANDING_ORIGIN` to that website's HTTPS origin. The static page issues its first Flex request on the click.

Register the exact temporary `/api/callback/linkedin` URL in the existing LinkedIn developer app after approval. The test uses the desk's confidential authorization-code flow with a session-bound OAuth state and validates the signed LinkedIn ID token. Time the static landing click to the member search form, then submit a known synthetic name and record the elapsed time to its result. Exercise the unmatched control from `/api/test` with the same signed-in LinkedIn account and verify HTTP 403 on `/api/desk`. Verify an unsigned request to `/api/desk` receives HTTP 403 and a callback without a valid session receives HTTP 401. The endpoint and OAuth state expire. Remove the temporary callback and resource group after the run.
