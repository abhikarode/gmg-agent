# Repository completion policy

The global Codex evidence discipline applies here.

Before claiming implementation work is complete:

1. Execute checks that directly exercise the requested behavior.
2. Run every required command in `.codex/verification.json` with `~/.codex/bin/codex-verify`.
3. Link each requirement to fresh execution evidence for the active session.
4. Never substitute fixtures, mocks, or inferred results for production evidence.
5. Record limitations and unresolved blockers explicitly.
